# Full Stack İnsan Kaynakları Uygulaması

Bu proje, insan kaynakları süreçlerini yönetmek için geliştirilmiş bir **full stack web uygulamasıdır**. Arka uçta (backend) güvenli ve modüler bir **Spring Boot** mimarisi, ön yüzde (frontend) ise hızlı ve kullanıcı dostu bir **React + Vite** mimarisi kullanılmıştır.

---

## 🧠 Kullanılan Ana Teknolojiler

### 🔧 Backend (Java + Spring Boot)

| Teknoloji | Açıklama |
|----------|----------|
| **Java 21** | Projenin backend dili |
| **Spring Boot 3.4.5** | Mikroservis yapısına uygun, modüler yapı |
| **Spring Web** | RESTful API geliştirme |
| **Spring Security** | Kimlik doğrulama ve yetkilendirme |
| **OAuth2 Resource Server** | JWT token doğrulama |
| **Spring Data JPA (Hibernate)** | ORM ile veritabanı etkileşimi |
| **PostgreSQL** | İlişkisel veritabanı |
| **Javax Mail** | E-posta gönderimi (aktivasyon, bildirim) |
| **Java JWT (Auth0)** | JWT token üretimi ve çözümlemesi |
| **Springdoc OpenAPI (Swagger UI)** | API dokümantasyonu ve test arayüzü |
| **Lombok** | Kod tekrarını azaltmak için getter/setter otomasyonu |

---

### 🎨 Frontend (React + TypeScript + Vite)

| Teknoloji | Açıklama |
|----------|----------|
| **React 19** | Component tabanlı kullanıcı arayüzü |
| **TypeScript** | Tip güvenliği ve geliştirme kolaylığı |
| **Vite** | Hızlı geliştirme ve derleme aracı |
| **React Router v7** | Sayfa yönlendirme ve route yönetimi |
| **Axios** | API istekleri için HTTP istemcisi |
| **JWT Decode** | JWT token çözümlemesi (kullanıcı bilgisi çıkarımı) |
| **Styled-components / Emotion / MUI** | Stilling için kombinasyonlu yapı (CSS-in-JS + bileşen kütüphanesi) |
| **Bootstrap + React Bootstrap** | Grid ve UI bileşenleri desteği |
| **React Toastify** | Kullanıcıya toast mesajları gösterme |
| **SweetAlert2** | Kullanıcıya interaktif uyarılar (modallar, onaylar) |
| **Chart.js + react-chartjs-2** | Grafik ve veri görselleştirme |
| **Lucide React** | Hafif ve özelleştirilebilir ikon seti |
